# 2. Bing Webmaster Tools  (~5 min — quick win)

**URL:** https://www.bing.com/webmasters

## Step-by-step

1. Sign in with a Microsoft account (create one if needed — use
   `support@advocat.ee` to keep credentials tidy).
2. Click **"Add a site"** → enter `https://advocat.ee` → **Add**.
3. **Easy path:** Bing offers **"Import from Google Search Console"**
   on the very first screen. Click it — one OAuth click and the site
   is verified instantly (since GSC is already set up per
   `setup_checklist.md`).
4. **If import is skipped or fails**, use HTML meta-tag verification:
   - Bing will generate a tag like
     `<meta name="msvalidate.01" content="XXXXXXXXXXXXXXXXXXXXXXXX">`
   - The placeholder is already in `web/index.html`. Replace
     `YOUR_VERIFICATION_CODE` with the value Bing gives you, then
     `npm run build` and `./scripts/canary-deploy.sh`.
   - Click **Verify** in Bing.
5. **Alternative — XML file method** (skip unless meta-tag fails):
   - Bing will offer to download `BingSiteAuth.xml`.
   - Upload it to `web/BingSiteAuth.xml` so it serves at
     `https://advocat.ee/BingSiteAuth.xml`.
   - Then deploy via canary.

## After verification — submit sitemap

- In the left nav → **Sitemaps** → **Submit sitemap**.
- Paste: `https://advocat.ee/sitemap.xml`
- Click **Submit**. Indexing starts within 24h.

## Expected timeline

- Verification: instant (if importing from GSC) or 1–10 min (meta tag).
- First crawl: 24–48h.
- Pages indexed: 3–7 days.
